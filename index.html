Bienvenue ! Il ne reste qu'une étape : brancher ta base de données Firebase (gratuite).

  1. Va sur console.firebase.google.com et crée un projet (ex. « chats »).
  2. Dans Build → Authentication → Sign-in method, active E-mail/Mot de passe.
  3. Dans Build → Firestore Database, clique Créer une base de données → choisis un emplacement → Mode test → Activer.
  4. Dans Paramètres du projet (⚙️) → Vos applications → Web (</>), enregistre une app nommée « ChaTs », puis copie le bloc firebaseConfig affiché.
